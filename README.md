# Laith Abu Arrah — Portfolio

Personal portfolio built with React, Framer Motion, and Vite. It showcases full-stack development, graphic design, and graduation project work.

**Live site:** _add link after deployment_

## Sections

- **Hero**: introduction and contact links
- **About**: background in development and design
- **Skills**: development, design, and engineering tools
- **Projects**: Project Campus, a unified academic social platform
- **Graphics**: selected design work
- **Contact**: email, phone, and a contact form (Formspree)

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Tech stack

React · Vite · Framer Motion · CSS
